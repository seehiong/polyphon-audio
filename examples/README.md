# Example assets

- **`voice.wav`** — an 8-second public-domain LibriVox clip (*"My Heart
  and I"*, Elizabeth Barrett Browning, read by a LibriVox volunteer;
  source
  [archive.org/details/short_poetry_065_librivox](https://archive.org/details/short_poetry_065_librivox),
  file `myheartandi_barrettbrowning_jvw.mp3`). Public domain in the USA;
  the reader donated the recording for reuse including derivatives. Used
  as a rights-cleared reference clip for voice-cloning tests
  (`--speaker-wav`/`--voice-ref`).
- **`script.txt`** — a short narration text used for the same tests.
- **`voice_synthetic.wav`** — not a recording of anyone: generated by
  `qwen3_tts`'s VoiceDesign model from the text instruction *"A calm,
  warm, middle-aged male narrator voice, clear articulation, slight
  British accent"* (see README's "Voice design" bullet). No
  rights/provenance question at all, unlike a clip sourced from a real
  recording — that's the point of using it here. Says,
  self-referentially, "I'm a synthetic voice, designed from a written
  description rather than cloned from anyone's recording."
- **`voices.example.json`** / **`dialogue_script.json`** — a two-voice
  narration demo for `scripts/narrate.py`: `"narrator"` is `voice.wav`
  (the LibriVox clip), `"companion"` is `voice_synthetic.wav`. Copy to
  `voices.json` (gitignored) to use as-is, or point either entry at your
  own reference clips.
